Esto es un pequeño bot creado en el curso de Boot.dev que analiza un libro de texto y da ciertas caracteristicas, no es nada complejo pero es algo que hice para no perder la costumbre del programar y no dejar de pensar con la logica de la programacion.

FORMA DE USO:

Es un bot simple donde al inicializarse desde una terminal se le pasa el path donde esta el libro, el bot lo busca y una vez lo obtiene manda de forma ordenada el cuantas palabras tiene y cuantas de cada unas de las letras se uso en el mismo.

===========================================================================================================================================

This is a small bot created during the Boot.dev course that analyzes a text file and reports specific characteristics. It is nothing complex, but I built it to keep up my coding habits and stay in the mindset of programming logic.

HOW TO USE:

It is a simple bot when you launch it from a terminal, you provide the path to the text file. The bot locates and reads the file, then outputs a structured report showing the total word count and the frequency of each letter used within the text.
